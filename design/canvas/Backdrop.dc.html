Gradient descent

Gradient descent is an iterative method for finding a minimum of a differentiable function. Starting from an initial guess, it repeatedly steps in the direction opposite the gradient — the direction in which the function decreases fastest.

Learning rate

The size of each step is set by a parameter called the learning rate, often written η. A rate that is too small makes progress slow; one that is too large can overshoot the minimum and cause the iterates to diverge.

xn+1 = xn − η ∇f(xn)

In machine learning, the function being minimized is usually a loss measured over training data. Variants such as stochastic gradient descent estimate the gradient from small batches of examples rather than the full dataset.

Convergence

For convex functions with a suitably chosen step size, gradient descent converges to the global minimum. For non-convex functions it may settle in a local minimum or a saddle point.
